2. Parse, Don't Validate: Live Smart-Constructor Gate

In Laravel, a FormRequest validates a string at the HTTP edge, yet downstream methods still accept any plain string. In Gleam, marking GrrrBody as a pub opaque type hides its constructor outside grrr/post — making unvalidated posts a compile error.

Laravel (Runtime Convention)

// StoreGrrrRequest.php
public function rules(): array {
  return ['body' => ['required', 'string', 'max:280']];
}

// Downstream still accepts any plain string:
function publish(string $body): Grrr { ... }

If another caller skips the FormRequest, PHP happily accepts "" or 1,000 chars.

Gleam (Compile-Time Proof)

pub opaque type GrrrBody {
  GrrrBody(String)
}

// Downstream requires the proof type:
pub fn publish(body: GrrrBody) -> ...

External modules cannot call GrrrBody(""). Passing a raw String to publish refuses to compile.

3. Hands-On Lab (8 minutes)

Open your terminal at the root of your lesson-0001/ worktree (see REPO-MANAGEMENT.md) and build the first real package of grrr.

  1. Scaffold the shared Gleam package 
    # From the lesson-0001/ worktree root
gleam new shared
cd shared
gleam test
    You should see 1 passed, 0 failures immediately.
  2. Create shared/src/grrr/post.gleam 
    import gleam/string

pub const max_body_length = 280

pub opaque type GrrrBody {
  GrrrBody(String)
}

pub type BodyError {
  Empty
  TooLong(length: Int, max: Int)
}

pub fn new_body(raw: String) -> Result(GrrrBody, BodyError) {
  let trimmed = string.trim(raw)
  let len = string.length(trimmed)

  case len {
    0 -> Error(Empty)
    n if n > max_body_length -> Error(TooLong(length: n, max: max_body_length))
    _ -> Ok(GrrrBody(trimmed))
  }
}

pub fn to_string(body: GrrrBody) -> String {
  let GrrrBody(text) = body
  text
}
  3. Write tests in shared/test/grrr_post_test.gleam and run gleam test 
    import gleeunit/should
import grrr/post.{Empty, TooLong}

pub fn valid_body_trims_whitespace_test() {
  let assert Ok(body) = post.new_body("  hello gleam 🐻  ")
  post.to_string(body)
  |> should.equal("hello gleam 🐻")
}

pub fn whitespace_only_is_empty_error_test() {
  post.new_body("   \n\t  ")
  |> should.equal(Error(Empty))
}

pub fn over_280_graphemes_is_too_long_test() {
  let long = "a" |> repeat(281)
  post.new_body(long)
  |> should.equal(Error(TooLong(length: 281, max: 280)))
}

fn repeat(s: String, times: Int) -> String {
  case times <= 0 {
    True -> ""
    False -> s <> repeat(s, times - 1)
  }
}
    Run gleam test — all tests should pass!
  4. 2-Minute Proof: Try to cheat your own type
    In grrr_post_test.gleam, temporarily call post.GrrrBody("bypass") and run gleam test. Watch the compiler block it because GrrrBody is opaque, then delete that line so your suite is green again.
