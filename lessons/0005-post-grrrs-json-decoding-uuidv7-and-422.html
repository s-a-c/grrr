1. The End-to-End Write Boundary (Zero Unvalidated Writes)

Notice how Gleam's use expression unifies four completely different layers in one flat controller handler: HTTP JSON parsing (wisp.require_json), structural decoding (decode.field), domain validation (post.new_draft_all), and SQLite persistence (grrr.create_or_fail).

Three Write-Boundary Guarantees

  • wisp.require_json pre-check: Runs before decode.run and short-circuits immediately with 415 Unsupported Media Type if Content-Type is not JSON, or 400 Bad Request on invalid JSON syntax.
  • Why uuid.v7_string() over auto-increment integers: UUIDv7 is time-ordered (k-sortable) and generated locally without a database round-trip, while hiding sequential row counts from users.
  • Unwrapping at the DB edge: Only inside the final persistence call do we unwrap opaque types via handle.to_string(draft.author) and post.to_string(draft.body) into plain SQLite strings.

2. schema.timestamps() vs. schema.unix_timestamps()

In Lesson 0004 we started with schema.unix_timestamps(). Before we build our write path and JSON API responses, let's compare Glimr's two built-in timestamp helpers and switch grrrs to schema.timestamps():

Feature schema.timestamps() schema.unix_timestamps()
SQLite column TEXT (ISO 8601 / RFC 3339 string) INTEGER (seconds since Unix epoch)
PostgreSQL column TIMESTAMP WITH TIME ZONE BIGINT (64-bit integer)
Generated Gleam type String (e.g. "2026-11-23T05:30:00Z") Int (e.g. 1795411800)
Glimr / Gleam helper gleam/time/timestamp.to_rfc3339 glimr/utils/unix_timestamp.now()
Strengths Human-readable in SQLite & JSON, timezone-aware in Postgres, sub-second precision, standard for REST/Lustre APIs. Compact 8-byte integer, trivial TTL arithmetic (expires_at > now) for sessions & caches.

Bonus: Watch Glimr's Auto-Migration Diff in Action

Because Lesson 0004 already migrated grrrs with unix_timestamps(), swapping to schema.timestamps() and running ./glimr db_gen --migrate lets you see Glimr's snapshot differ automatically generate an ALTER/table-rebuild migration and update gen/grrr.gleam from Int to String.

    import app/app.{type App}
import database/main/models/grrr/gen/grrr.{type Grrr}
import gleam/dynamic/decode
import gleam/int
import gleam/json
import gleam/time/duration
import gleam/time/timestamp
import glimr/http/context.{type Context}
import glimr/http/response.{type Response}
import grrr/handle
import grrr/post.{type DraftError, Empty, InvalidBody, InvalidHandle, TooLong}
import wisp
import youid/uuid

/// List the 50 most recent Grrrs as JSON.
///
/// @get "/api/grrrs"
///
pub fn index(ctx: Context(App)) -> Response {
  use grrrs <- grrr.list_recent_or_fail(ctx.app.db)

  json.object([
    #("grrrs", json.array(grrrs, encode_grrr)),
  ])
  |> response.json(200)
}

/// Validate and persist a new Grrr with a time-ordered UUIDv7.
///
/// @post "/api/grrrs"
///
pub fn store(ctx: Context(App)) -> Response {
  use json_body <- wisp.require_json(ctx.req)

  let payload_decoder = {
    use author <- decode.field("author", decode.string)
    use body <- decode.field("body", decode.string)
    decode.success(#(author, body))
  }

  case decode.run(json_body, payload_decoder) {
    Error(_) ->
      json.object([#("error", json.string("Expected JSON with author and body strings"))])
      |> response.json(400)

    Ok(#(raw_author, raw_body)) ->
      case post.new_draft_all(raw_author, raw_body) {
        Error(errors) ->
          json.object([#("errors", json.array(errors, encode_draft_error))])
          |> response.json(422)

        Ok(draft) -> {
          let now =
            timestamp.system_time()
            |> timestamp.to_rfc3339(duration.seconds(0))
          let id = uuid.v7_string()

          use saved <- grrr.create_or_fail(
            pool: ctx.app.db,
            uuid: id,
            author_handle: handle.to_string(draft.author),
            body: post.to_string(draft.body),
            created_at: now,
            updated_at: now,
          )

          json.object([#("grrr", encode_grrr(saved))])
          |> response.json(201)
        }
      }
  }
}

fn encode_grrr(item: Grrr) -> json.Json {
  json.object([
    #("id", json.string(item.uuid)),
    #("author_handle", json.string(item.author_handle)),
    #("body", json.string(item.body)),
    #("created_at", json.string(item.created_at)),
  ])
}

fn encode_draft_error(err: DraftError) -> json.Json {
  let #(field, message) = case err {
    InvalidHandle(handle.TooShort(len, min)) -> #(
      "author",
      "Handle too short (" <> int.to_string(len) <> "/" <> int.to_string(min) <> " min)",
    )
    InvalidHandle(handle.TooLong(len, max)) -> #(
      "author",
      "Handle too long (" <> int.to_string(len) <> "/" <> int.to_string(max) <> " max)",
    )
    InvalidHandle(handle.InvalidChars) -> #(
      "author",
      "Handle may only contain letters, numbers, and underscores",
    )
    InvalidBody(Empty) -> #("body", "Grrr body cannot be empty")
    InvalidBody(TooLong(len, max)) -> #(
      "body",
      "Grrr body too long (" <> int.to_string(len) <> "/" <> int.to_string(max) <> " max)",
    )
  }

  json.object([
    #("field", json.string(field)),
    #("message", json.string(message)),
  ])
}
