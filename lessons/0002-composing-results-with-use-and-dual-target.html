1. Escaping the Pyramid of Doom: Gleam's use

In Lesson 0001 you validated one field (GrrrBody). Real grrr actions validate several things in sequence: an author Handle, a GrrrBody, maybe a reply target ID. Without syntax help, chaining Results with case indents deeper at every step.

Gleam solves this with use expressions — pure syntax sugar that passes the rest of your block as a callback to a higher-order function like result.try. You will also use use in every Glimr controller and middleware (Wisp) starting in Lesson 0003!

Laravel Early Return

Validate step 1 or throw ValidationException; validate step 2 or throw. Flat to read, but failure types are invisible in signatures.

Gleam use <- result.try

Reads top-to-bottom just like early returns, short-circuits on the first Error, and keeps every failure in the return type.

result.map_error

HandleError and BodyError are different types. Wrap each into a unified DraftError so result.try can chain them.

Interactive Comparison: Flat use vs Desugared result.try

pub fn new_draft(raw_author: String, raw_body: String) -> Result(DraftGrrr, DraftError) {
  use author <- result.try(
    handle.new(raw_author) |> result.map_error(InvalidHandle),
  )
  use body <- result.try(
    new_body(raw_body) |> result.map_error(InvalidBody),
  )

  Ok(DraftGrrr(author:, body:))
}

Idiomatic use: Flat, linear, zero rightward drift. The compiler literally rewrites this into the nested callback version.

3. Hands-On Lab (9 minutes)

Add Handle and DraftGrrr inside shared/, then prove your domain core runs on both Erlang/BEAM and JavaScript.

  1. Create shared/src/grrr/handle.gleam
    Normalizes optional leading @, lowercases, enforces 3–15 characters in [a-z0-9_], and seals the constructor with pub opaque type Handle: 
    import gleam/list
import gleam/string

pub opaque type Handle {
  Handle(String)
}

pub type HandleError {
  TooShort(length: Int, min: Int)
  TooLong(length: Int, max: Int)
  InvalidChars
}

pub fn new(raw: String) -> Result(Handle, HandleError) {
  let cleaned =
    raw
    |> string.trim
    |> strip_leading_at
    |> string.lowercase

  let len = string.length(cleaned)
  case len {
    n if n < 3 -> Error(TooShort(length: n, min: 3))
    n if n > 15 -> Error(TooLong(length: n, max: 15))
    _ ->
      case is_valid_chars(cleaned) {
        True -> Ok(Handle(cleaned))
        False -> Error(InvalidChars)
      }
  }
}

pub fn to_string(handle: Handle) -> String {
  let Handle(name) = handle
  "@" <> name
}

fn strip_leading_at(s: String) -> String {
  case string.starts_with(s, "@") {
    True -> string.drop_start(s, 1)
    False -> s
  }
}

fn is_valid_chars(s: String) -> Bool {
  s
  |> string.to_graphemes
  |> list.all(fn(ch) {
    string.contains("abcdefghijklmnopqrstuvwxyz0123456789_", ch)
  })
}
  2. Add DraftGrrr + new_draft to shared/src/grrr/post.gleam
    Add import gleam/result and import grrr/handle.{type Handle, type HandleError} at the top of post.gleam, then append: 
    pub type DraftGrrr {
  DraftGrrr(author: Handle, body: GrrrBody)

pub type DraftError {
  InvalidHandle(HandleError)
  InvalidBody(BodyError)
}

pub fn new_draft(
  raw_author: String,
  raw_body: String,
) -> Result(DraftGrrr, DraftError) {
  use author <- result.try(
    handle.new(raw_author) |> result.map_error(InvalidHandle),
  )
  use body <- result.try(
    new_body(raw_body) |> result.map_error(InvalidBody),
  )

  Ok(DraftGrrr(author:, body:))
}
  3. Add tests in shared/test/grrr_draft_test.gleam
    Notice how we use string.repeat from gleam/string instead of a custom helper! 
    import gleam/string
import gleeunit/should
import grrr/handle
import grrr/post.{Empty, InvalidBody, InvalidHandle, TooLong}

pub fn valid_draft_normalizes_handle_and_body_test() {
  let assert Ok(draft) = post.new_draft("  @Bear_Dev ", "  Hello grrr! 🐻 ")
  handle.to_string(draft.author) |> should.equal("@bear_dev")
  post.to_string(draft.body) |> should.equal("Hello grrr! 🐻")
}

pub fn invalid_handle_short_circuits_before_body_test() {
  // Both handle AND body are invalid — handle error wins first
  post.new_draft("ab", "")
  |> should.equal(Error(InvalidHandle(handle.TooShort(length: 2, min: 3))))
}

pub fn invalid_body_returns_invalid_body_error_test() {
  post.new_draft("@valid_user", "   ")
  |> should.equal(Error(InvalidBody(Empty)))
}

pub fn exact_280_graphemes_is_allowed_test() {
  let max_emojis = string.repeat("🐻", 280)
  let assert Ok(draft) = post.new_draft("bear", max_emojis)
  string.length(post.to_string(draft.body)) |> should.equal(280)
}

pub fn over_280_graphemes_returns_too_long_test() {
  let over = string.repeat("a", 281)
  post.new_draft("bear", over)
  |> should.equal(Error(InvalidBody(TooLong(length: 281, max: 280))))
}
